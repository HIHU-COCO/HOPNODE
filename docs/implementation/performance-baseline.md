# A25 性能测量草案（未冻结）

日期：2026-10-19；作者：HIHU-COCO。关联 P05 / K04 / I12 / A25。状态：BLOCKED，未进行产品性能验收。

现有 Windows 11 x64 与 WSL Ubuntu 22.04 只用于工程/隔离 POC；没有不同网络和强制 DERP 的授权端点，也没有产品 Directory、调度器或 task-runner。10 MiB loopback SFTP 成功仅证明该次文件完整性，不推导公网速率或 1 GB 能力。

| 测量 | 试验规模与采样 | 阈值草案 / 冻结条件 |
| --- | --- | --- |
| 目录发现/离线 | 100 条逻辑设备；真实数量另记；采集至少 100 次发现的 p50/p95/max | PRD 已要求正常网络就绪后 15 秒内出现；10/30/60 秒为可配置心跳/待确认/离线默认值；实际误差待 POC |
| 列表查询 | 100 条设备、30 分钟心跳；记录 p95 时延、错误、CPU/RSS、日志字节 | 暂提本机 p95 ≤ 1 秒作为试验假设，需注明硬件并在 K04 审核，不是承载声明 |
| 并行命令 | 10 个授权目标；真实与模拟分列；每目标 100 次轻量命令 | 暂提已连通目标完成率 100%、无串设备、无未知结果自动重试；调度延迟阈值待网络基线 |
| SFTP | 精确 1,000,000,000 字节随机文件，中文/空格路径；直连与 DERP 各 3 次 | 三次完整性 SHA-256 均一致；吞吐记录 p50/min；不设未经实测的中继最低速率 |
| 断线/恢复 | Windows/Linux，manual SSH 与 managed 分别至少 10 次 | managed 最终状态可查询且不重复执行；manual 的未知/不保证存活必须准确；恢复时延待 task-runner POC |
| 长时间运行 | 100 逻辑设备 + 10 目标并发，60 分钟 | 记录基线/峰值内存、CPU、错误率、日志增长；资源上限需依据 POC 硬件实测后设定 |

每轮必须保存脱敏环境、组件版本、网络路径证据、原始样本摘要、命令、结果和日期。模拟目录不得计作 100 台实体跨网设备。K04 未签收前表中建议数字均不生效；A25 仍 NOT_RUN，正式 27 项验收不得标 PASS。
