## Codex CLI 隔离注册

使用 README 的独立临时 CODEX_HOME 流程执行；编译服务同上。实际摘要：


`codex mcp get hopnode --json` 和 `codex mcp list --json` 成功读取 `name=hopnode`、`enabled=true`、`transport.type=stdio`、目标为本次临时可执行文件、空参数列表；list 的 `auth_status=unsupported`。临时 CODEX_HOME 之外的配置、认证文件、SSH 和 Tailscale 均未修改。finally 恢复调用进程原 CODEX_HOME。
