# K01 草案完整性审查与补齐清单

日期：2026-10-19。审查：desktop_finish；整理：集成负责人。状态：DRAFT 审查记录，不改变 P05/G1/K01 门槛，不表示接口已冻结或功能已实现。

依据：Design §3.4–3.6、§7–10、§12、§14.2，Plan K01，以及 [候选矩阵](K01-contract-draft.md)。对象为 `tests/pocs/contracts-draft/schemas/`；本轮仅本地只读审查，没有访问测试机、执行模型调用或运行业务测试。

现有草案验证了局部字段和正反例。26 个工具输入、58 个样例及十个基础错误码均不能代替完整结果、协议、身份和共享类型。下列内容须在 K01 完成判据中逐项落实。

| 顺序 | 当前缺口 | 必须形成的契约与验证 |
| --- | --- | --- |
| 1 | `core-api.schema.json` 仅六个 CoreRequest，无对应 CoreResponse | 请求/响应/事件区分、request_id 关联、方法与结果映射、framing、消息大小、超时/关闭及握手前错误 |
| 2 | 候选矩阵中的多数 IPC 方法尚无机器结构 | 设备/连接/Host Key、角色/托管、服务、Codex、文件/传输、命令/任务、终端尺寸、备份/历史/日志的输入和结果 |
| 3 | `mcp-tools.schema.json` 结果引用通用任意 object data | 26 个工具逐项结果，包括命令流/退出/超时、文件版本/编码/修改、传输字节/校验/部分完成、终端 session/尺寸/offset、任务/备份/历史分页 |
| 4 | Core Device 与 DirectoryDevice 字段不一致，缺共享能力模型 | 收敛基础类型及本地/目录投影；补 OS/地址/版本/备注/能力；网络、SSH 和链路状态分别表达，不能伪造手动设备心跳 |
| 5 | Directory 八操作中五项仍为 inventory-only | enrollment/register/heartbeat/disable/healthz 的完整请求、结果和负例；有效期/消费/重放、HTTP query/并发条件/状态码/关联 ID |
| 6 | 撤销与重绑定仍主要是原则 | 授权版本、撤销时间、key ID、重绑定审计；目录、网络、托管凭据、可归属会话分别报告落实/失败；秘密不进入普通 Device DTO |
| 7 | 调用身份与授权尚未形成方法矩阵 | OS peer、用户 controller、系统 agent、目标 SSH 账号及组织/设备身份绑定；Directory securitySchemes 和权限矩阵；请求自报身份不能代替认证 |
| 8 | CancelTask/CancelOperation 的 operation_id 可能混淆自身与目标 | 分离取消请求幂等 ID 和目标操作 ID；MCP request 到业务操作映射；完成竞争、重复/失败取消、前后台断线语义；只有执行器确认停止才能 canceled |
| 9 | 幂等与未知结果尚未成为可验证规则 | 调用身份/目标/摘要绑定、相同请求重试、不同请求冲突、并发、持久化/保留、记录不存在；可能已提交时保留原 ID、先查询、不自动重放 |
| 10 | `ipc-events.schema.json` 仅三类事件 | 补连接/传输/终端/Agent/Service/MCP 的事件或明确查询/流替代；订阅授权、资源顺序、重复/丢失、重连/保留/恢复、无设备服务事件 |
| 11 | 版本字段存在但协商和入口错误映射不完整 | 客户端范围/服务范围有效性、不兼容与未知方法/枚举行为；协议/业务/HTTP/CLI/远端退出码/MCP isError 与内容的一致映射 |
| 12 | 资源上限与共享类型尚未兑现 | 页/字节/超时/终端缓冲/流生命周期的默认和上限；受保护流引用、cursor 失效、条件写/备份；Go/TS 共享或生成类型、完整 OpenAPI 校验和对应反例 |

建议施工顺序：先收敛 envelope、共享模型、方法与逐工具结果，再补 Directory 身份/停用结构；随后完成取消/幂等、事件、兼容与有界资源规则，最后以生成类型及契约测试验证一致性。安全策略应先形成明确决策和失败行为，再冻结相应结构；平台能力和性能阈值仍需对应 POC/K04 证据。

若 [P05 替代施工顺序](P05-conditional-development.md) 获明确授权，由集成负责人按上述清单推进正式 K01；此前仅允许独立草案和检查，不启动依赖冻结契约的业务线。此记录不将任何 A01–A27 项目改为 PASS。
